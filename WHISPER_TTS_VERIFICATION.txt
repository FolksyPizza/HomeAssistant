================================================================================
ISSUE IDENTIFIED
================================================================================

The Whisper (speech-to-text) and Piper (text-to-speech) AI features were not
being properly initialized despite correct configuration in the .env file.

ROOT CAUSE:
  Environment variables from .env were not being loaded in production builds.
  - SvelteKit's $env/dynamic/private reads from process.env
  - Node.js doesn't automatically load .env files
  - This caused all Pi-local voice features to be disabled

================================================================================
FIX APPLIED
================================================================================

1. Added 'dotenv' npm package (--save-dev)
2. Updated package.json start script:
   
   OLD: "start": "HOST=0.0.0.0 PORT=8989 node build"
   NEW: "start": "HOST=0.0.0.0 PORT=8989 node --require dotenv/config build"

EXPLANATION:
  The --require dotenv/config flag loads environment variables from .env
  before the application code runs.
